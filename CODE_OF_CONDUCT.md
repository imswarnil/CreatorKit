# Code of conduct

Be decent to people.

Assume good faith, keep criticism about the code, and take the hint when someone asks you
to drop it. Harassment, personal attacks and deliberate derailing are not welcome here and
will get you removed without much ceremony.

This applies in issues, pull requests, commit messages and anywhere else the project has a
presence.

If someone is making the project worse to be part of, report it to the address in
[`SECURITY.md`](./SECURITY.md). Reports stay between you and the maintainer.
