# Changelog

Release notes for the `@creatorkit/*` packages are generated by
[Changesets](https://github.com/changesets/changesets) and live in each package's own
`CHANGELOG.md`. This file records changes to the repository itself.

## 0.1.0

The first release. A complete CSS design system for creators, a React layer growing out of
it, a Ghost theme, a starter template and a documentation site — all on one foundation.

**Foundation**

- `@creatorkit/tokens` — 332 custom properties (58 with dark overrides) plus the reset,
  a11y, layout, pattern, frame, cutout, logo and icon layers. The CSS is the source of
  truth; the Tailwind preset, `tokens.json` and `TOKENS.md` are generated from it, and the
  build fails if the naming map references a property no stylesheet declares.

**The kit** — 1,143 classes across five packages

- `@creatorkit/ui` — 285 classes: buttons, cards, forms, navs, alerts, media, overlays,
  disclosures, timelines, comments, heroes, stats, CTAs, footers. Plus eight React
  components.
- `@creatorkit/collections` — 22 creator content types, from `c-video` to `c-changelog`,
  with page templates.
- `@creatorkit/core` — 202 `u-*` utilities, the focus ring, `cn()`, polymorphic types.
- `@creatorkit/broadcast` — 139 classes for YouTube and Instagram: thumbnails, series art,
  scenes, lower thirds, engagement overlays. Never in a site bundle.
- `@creatorkit/icons` — 55 icons in six sets, built to a sprite and a typed name union.

**One recipe, two renderers**

- React components declare appearance once as a CVA recipe; `tools/recipe-to-css` compiles
  the same object into `.ck-*` classes for Handlebars. A test fails the build if the two
  ever disagree.

**Everything else**

- `apps/docs` — 100 pages, 224 live examples, generated variant galleries and prop tables.
- `templates/youtuber-portfolio` — a static one-page site; edit one config file, run one
  build, host the folder.
- The Ghost theme, on the kit, gscan clean for Ghost 6.
- `tools/` — recipe-to-css, props-gen, css-inventory, icon-build, kit-docs. Every
  inventory and reference in the repo is generated, so none of them can go stale.

**Known gaps**

- The React layer covers primitives only; the CSS kit is complete. See `docs/MIGRATION.md`.
- No search on the docs site yet.
- Nothing is published to npm; the scope is not registered.
